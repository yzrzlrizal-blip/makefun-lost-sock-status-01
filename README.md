One status update of 120 characters at most, written in the voice of a lost sock that has ended up behind the dryer — and has something to say about its partner moving on.

> Day 12 behind the dryer. My partner has a new sock now. I get it. I would leave me too. I smell like lint and regret.

## Run it

```sh
python3 main.py
```

Writes the status update to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), self-checking it is 1–120 characters and a single line.
